# Generative AI Research

This repository contains all project files related to our research on the use of Generative AI tools.

## 📂 Folder Structure
- `Literature_Review/`: Journal articles, books, and newspaper clippings.
- `Quantitative_Analysis/`: Survey questions, data, Python analysis scripts.
- `Qualitative_Analysis/`: Interview transcripts, consent forms, insights report.
- `Drafts_Reports/`: Research proposals and final reports.
- `Media/`: Photos and media files.

## 📌 How to Navigate
- All data is categorised by type in separate folders.
- Use the `Analysis_development` branch to view in-progress data scripts.

## 🤝 How to Contribute
1. Fork this repository
2. Create a new branch (`feature/yourname-task`)
3. Make your changes and commit with clear messages
4. Submit a Pull Request for review
